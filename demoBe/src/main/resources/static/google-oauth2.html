Google OAuth2 Login (Code Flow)

Click button below to login with Google using OAuth2 Code Flow

🔵 Login with Google

How it works:

  1. Click button → Redirect to Google
  2. Google asks for permission
  3. Google redirects back with code
  4. Backend exchanges code for token
  5. Success handler creates session & JWT
  6. Redirect to frontend with JWT

Note: After successful login, you'll be redirected to http://localhost:3000/oauth/callback?token=...

Make sure your frontend is running on port 3000 to receive the token!
